# Unity Visual Scripting Projects

## Overview

This repository contains Unity projects that I developed using **Unity Visual Scripting** to explore core game development concepts without traditional C# programming. Each project focuses on implementing gameplay mechanics through Unity's node-based visual scripting system, helping me build a stronger understanding of player input, movement, and interactive game behavior.

---

## Projects Included

### 1. Clive

**Clive** is a Unity Visual Scripting project that demonstrates player movement and jumping mechanics. The project focuses on creating a responsive character controller using visual scripting graphs instead of code.

#### Features

* WASD movement controls
* Spacebar jump functionality
* Physics-based movement
* Keyboard input handling through Visual Scripting
* Beginner-friendly character controller implementation

#### Controls

| Key      | Action        |
| -------- | ------------- |
| W        | Move Forward  |
| A        | Move Left     |
| S        | Move Backward |
| D        | Move Right    |
| Spacebar | Jump          |

#### What I Learned

* Creating movement systems with Visual Scripting
* Working with player input events
* Implementing jump mechanics
* Applying Unity physics to gameplay interactions

### 2. Basic Controls Demo

**Basic Controls Demo** is a simple Unity Visual Scripting project designed to demonstrate fundamental object movement using keyboard controls. The project serves as an introduction to handling user input and moving game objects through visual scripting.

#### Features

* Four-directional movement
* Keyboard input detection
* Visual Scripting implementation
* Simple object control system

#### Controls

| Key | Action        |
| --- | ------------- |
| W   | Move Forward  |
| A   | Move Left     |
| S   | Move Backward |
| D   | Move Right    |

#### What I Learned

* Handling keyboard input in Unity
* Designing Visual Scripting graphs
* Creating reusable movement logic
* Understanding event-driven gameplay systems
