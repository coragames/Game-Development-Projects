# Unity Visual Scripting: WASD Movement & Jump Controls

## Overview

This project demonstrates basic player movement using **Unity Visual Scripting**. The object can be controlled using the keyboard, allowing movement in four directions with the **W**, **A**, **S**, and **D** keys, and jumping with the **Spacebar**.

The purpose of this project is to provide a beginner-friendly example of implementing character controls without writing code, using Unity's node-based Visual Scripting system.

---

## Features

* **W** – Move Forward
* **A** – Move Left
* **S** – Move Backward
* **D** – Move Right
* **Spacebar** – Jump
* Built entirely using **Unity Visual Scripting**
* Beginner-friendly project structure

---

## Controls

| Key      | Action        |
| -------- | ------------- |
| W        | Move Forward  |
| A        | Move Left     |
| S        | Move Backward |
| D        | Move Right    |
| Spacebar | Jump          |

---

## How It Works

The Visual Scripting graph performs the following actions:

1. Detects keyboard input for movement keys.
2. Applies movement to the object along the X and Z axes.
3. Detects when the Spacebar is pressed.
4. Applies an upward force or movement to create a jump effect.
5. Updates the object's position during gameplay.
