# Zigg Zagg

**Zigg Zagg** is a fast-paced endless arcade game where players guide a rolling ball across a narrow zig-zag path. The objective is to stay on the platform, collect coins, and achieve the highest score possible before falling off the edge.

## Gameplay

- Tap the screen (Mobile) or click the mouse (Windows, macOS, Web) to change the ball's direction.
- Navigate carefully along the endless zig-zag platform.
- Collect coins scattered along the path to increase your score.
- The game speed gradually increases over time, making it more challenging as you progress.
- Stay focused—one wrong move and the ball will fall off the platform!

## Features

- Endless arcade gameplay
- Simple one-touch / one-click controls
- Increasing difficulty with progressive speed
- Coin collection system
- Current score tracking
- Highest score (High Score) saved locally
- Game Over screen with:
  - Restart Game
  - Exit Game
- Lightweight and easy to play

## Controls

### Mobile (Android / iOS)

- **Tap anywhere on the screen** to change the ball's direction.

### Desktop (Windows / macOS)

- **Left Mouse Click** to change the ball's direction.

### Web

- **Mouse Click** to change the ball's direction.

## Scoring

At the end of each game, the Game Over screen displays:

- **Current Score** – Score earned in the current run.
- **Highest Score** – Best score achieved so far.

Players can restart the game and try to beat their highest score.

## Game Over

The game ends when:

- The ball falls off the zig-zag platform.

After Game Over, players can:

- Restart the game
- Exit the game

## Platforms

Zigg Zagg can be played on:

- Android
- iOS
- Windows
- macOS
- Web Browser
