# Dodge The Enemy

A simple and fun arcade-style game built with **Python**, **Pygame**, and **Tkinter**.

The objective is to survive as long as possible by dodging falling birds. Your score increases over time, and the highest score is saved between game sessions.

---

## Features

* Arrow key movement
* Random bird sizes
* Random bird speeds
* Collision detection
* Live score display
* Persistent high score
* Game Over screen
* Restart game with **R**
* Quit game with **Q**
* Pause game with **P**
* Background music and sound effects
* Tkinter-based main menu

---

## Controls

| Key     | Action                          |
| ------- | ------------------------------- |
| ← ↑ ↓ → | Move Player                     |
| P       | Pause / Resume                  |
| R       | Restart Game (Game Over Screen) |
| Q       | Quit Game                       |

---

## Gameplay

* Control the player using the arrow keys.
* Avoid the falling birds.
* Survive as long as possible to increase your score.
* Beat your previous high score.
