# Clive - Unity Visual Scripting Project

## Overview

I developed **Clive** as a Unity project to demonstrate basic player movement and jumping mechanics using **Unity Visual Scripting**. The goal of this project was to explore how gameplay functionality can be created without writing traditional C# code, instead relying on Unity's node-based visual scripting system.

In this project, the player can control an object using the keyboard, moving in four directions with the **WASD** keys and jumping with the **Spacebar**.

## Features

* Player movement using WASD controls
* Jump functionality using the Spacebar
* Built entirely with Unity Visual Scripting
* Real-time input handling
* Beginner-friendly implementation of movement mechanics

---

## Controls

| Key      | Action        |
| -------- | ------------- |
| W        | Move Forward  |
| A        | Move Left     |
| S        | Move Backward |
| D        | Move Right    |
| Spacebar | Jump          |

## How I Built It

Using Unity Visual Scripting, I created a graph that:

1. Detects keyboard input from the player.
2. Processes movement commands based on WASD key presses.
3. Updates the object's position accordingly.
4. Detects when the Spacebar is pressed.
5. Triggers a jump action by applying upward movement.
6. Uses Unity's physics system to handle movement behavior.

This approach allowed me to build interactive gameplay mechanics visually while gaining a better understanding of how game systems function behind the scenes.
