# Shoot and Shout

## Overview

**Shoot and Shout** is a fast-paced arcade shooting game developed using **Unity**. Players must use their mouse to shoot moving cards and earn as many points as possible before the timer runs out. Quick reflexes and accurate aiming are essential to achieve the highest score.

## Features

* Mouse-based shooting mechanics
* Moving target cards with different point values
* Negative scoring black cards that penalize the player
* Customizable game duration (60–300 seconds)
* Real-time score tracking
* Visual feedback and animations for successful and incorrect hits
* Mouse click sound effects
* Background music with Unity Audio Mixer integration
* Simple and intuitive user interface

## Gameplay

The objective of the game is to score the maximum number of points within the selected time limit.

### How to Play

1. Launch the game.
2. From the Main Menu, select a game duration between **60 and 300 seconds**.
3. Start the game.
4. Use the mouse cursor to aim at the moving cards.
5. Click on cards to shoot them:

   * **Point Cards:** Award points based on the number displayed on the card.
   * **Black Cards:** Deduct points from the player's score.
6. Continue shooting until the timer reaches zero.
7. The final score is displayed at the end of the game.

### Scoring System

| Card Type    | Effect                                 |
| ------------ | -------------------------------------- |
| Number Cards | Adds the displayed points to the score |
| Black Cards  | Subtracts points from the score        |
