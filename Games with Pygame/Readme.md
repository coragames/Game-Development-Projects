# Python Graphics & Game Development Projects

This repository contains a collection of beginner-to-intermediate level projects built using Python, primarily focusing on **Pygame** and basic graphics programming concepts. It includes interactive animations, GUI development, image processing, OpenGL 3D rendering, and a complete Snake Game implementation.

---

## Project List

### 12. Snake Game (Project)
A fully functional Snake Game built using Pygame.

#### Features:
- Snake movement using arrow keys  
- Food generation and collection  
- Score tracking  
- Snake growth mechanism  
- Self-collision detection  
- Screen wrapping (optional feature supported)  
- Pause / Resume functionality  
- Game over and restart options  

#### Controls:
- **Arrow Keys** → Move snake  
- **P** → Pause game  
- **C** → Continue  
- **Q** → Quit  
- **ESC** → Exit (in some states)

### 13. Dodge The Bird

A simple and fun arcade-style game built with **Python**, **Pygame**, and **Tkinter**.

The objective is to survive as long as possible by dodging falling birds. Your score increases over time, and the highest score is saved between game sessions.

---

## Features

* Arrow key movement
* Random bird sizes
* Random bird speeds
* Collision detection
* Live score display
* Persistent high score
* Game Over screen
* Restart game with **R**
* Quit game with **Q**
* Pause game with **P**
* Background music and sound effects
* Tkinter-based main menu

---

## Controls

| Key     | Action                          |
| ------- | ------------------------------- |
| ← ↑ ↓ → | Move Player                     |
| P       | Pause / Resume                  |
| R       | Restart Game (Game Over Screen) |
| Q       | Quit Game                       |
