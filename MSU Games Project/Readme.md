# Game Development Specialization (Michigan State University)

This repository contains my completed work for the **Game Development Specialization** offered by **Michigan State University**, one of the top-ranked game development programs in North America.

The specialization focuses on both the **theory and practice of game design**, with hands-on experience building multiple fully playable games using the **Unity game engine**.

---

# Overview

Throughout this specialization, I developed the skills required to:

- Design and develop interactive games from concept to prototype
- Understand core game design principles
- Implement gameplay mechanics using Unity
- Work with both 2D and 3D environments
- Build complete playable game systems

The program emphasizes a balance between **creative design thinking** and **technical game development skills**.

---

This repository includes four major game development projects built in Unity:
